# Real Audio Test Area

Place only run-time audio assets here.

Expected layout:

- `origin_vocal/` for original vocal reference files.
- `material_set/` for material audio folders.
- `lyrics/` for optional lyric files.
- `output/` for generated test output.

Only audio inputs and rendered outputs are used by the project scripts.
Metadata, cache, note, and scratch files in this area are ignored by Git.

Suggested case naming:

- `*_CN` for Chinese cases.
- `*_JP` for Japanese cases.

Use `cases.example.json` as the starting manifest for repeatable evaluation.
